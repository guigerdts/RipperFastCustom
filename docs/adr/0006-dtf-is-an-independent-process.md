# DTF is an independent production process

DTF lives in the production profile as its own process, with its own resolution, channel set,
white-ink mask, coverage and film substrate; it does not inherit offset angles, rulings or
limits. Colour channels and the white mask stay distinguishable in the model.

**Considered options**: treating DTF as a CMYK variant (rejected — it would silently import
offset parameters that do not apply).
